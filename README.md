# RC Plane Control Horn

A 3D printable control horn designed for small RC trainer aircraft.  
This repository includes STL for 3D printing, STEP file for CAD compatibility, and SpaceClaim source files for modification.

## Features

- Suitable for small RC trainer aircraft
- 4 pushrod adjustment holes
- Base mounting holes
- Reinforced support rib
- Designed for PLA+, PETG, ABS, or Nylon printing

## Recommended Print Settings

- Material: PLA+ for testing, PETG/Nylon for better strength
- Infill: 80% to 100%
- Wall count: 4 or 5
- Layer height: 0.2 mm
- Supports: Not required
- Print orientation: Base flat on bed

## Usage

Use the middle pushrod hole first for testing.  
After printing, perform a pull test before installing on the aircraft.
