# 3D Printing Instructions – RC Plane Control Horn

## Part
RC Plane Control Horn for small trainer aircraft control surfaces.

## Recommended Material

| Material | Use |
|---|---|
| PLA+ | Good for testing and small trainer aircraft |
| PETG | Better for real flying use |
| ABS | Good strength, needs enclosed printer |
| Nylon | Best strength, harder to print |

**Recommended for first print:** PLA+  
**Recommended for real flight:** PETG or Nylon

---

## Printer Settings

| Setting | Recommended Value |
|---|---:|
| Layer Height | 0.2 mm |
| Initial Layer Height | 0.2 mm |
| Infill | 80% to 100% |
| Wall Line Count | 4 to 5 |
| Top/Bottom Thickness | 1.2 mm minimum |
| Nozzle | 0.4 mm |
| Supports | Not required |
| Build Plate Adhesion | Brim or Skirt |
| Print Orientation | Base flat on bed |

---

## Print Orientation

Place the control horn with the **base plate flat on the print bed**.

This gives better mounting surface quality and easier printing.

Do not print the horn lying sideways unless you are testing different strength directions.

---

## Strength Settings

For RC aircraft use, do not print weak.

Use:

- 80% to 100% infill
- 4 or 5 wall lines
- 1.2 mm top/bottom thickness
- Good layer bonding
- Avoid brittle or old filament

---

## After Printing Checks

Before installing on the aircraft:

1. Check all holes are clear.
2. Insert the pushrod into the middle hole first.
3. Hold the base and pull the pushrod strongly by hand.
4. Check for bending near the horn base.
5. Check if mounting holes crack.
6. Check if the horn is firmly fixed to the control surface.

If it bends or cracks, increase horn thickness or print with PETG/Nylon.

---

## Installation Notes

- Use screw + glue for better strength.
- For foam or sunboard surfaces, use washer or backing plate if possible.
- Start with the middle pushrod hole.
- Use top hole only when more control throw is required.
- Perform control surface movement test before flight.

---

## Safety Note

This part is used in aircraft control. Test properly before real flight.

Do not use weak prints, low infill, or damaged parts.
